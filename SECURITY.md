# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue containing credentials, captured messages, personal data, exploit details or private deployment URLs.

Include the affected version, reproduction steps, impact and any suggested mitigation. Maintainers will acknowledge the report through the private advisory.

## Supported versions

Until the first tagged release, only the current `main` branch receives security fixes.

## Deployment responsibility

Operators are responsible for authentication, secret rotation, access policy, retention, Email Routing and protection of captured data. Review [docs/security.md](docs/security.md) before deployment.
